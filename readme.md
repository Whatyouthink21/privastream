# 🎬 VidSrc

A simple web-based video player integration using **VidSrc** as an external video source.

## ✨ Features

* 🎥 Embedded video playback
* 🌐 Web-based and lightweight
* 📱 Responsive interface
* ⚡ Fast loading
* 🔗 Supports external video embeds
* 🧩 Easy to integrate into existing projects

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

### 2. Open the project

No complicated setup is required for a basic HTML implementation.

```bash
index.html
```

Open the file in your browser or serve it using a local development server.

## 🔧 Example Integration

A basic iframe integration can look like:

```html
<iframe
    src="YOUR_VIDSRC_EMBED_URL"
    width="100%"
    height="500"
    frameborder="0"
    allowfullscreen>
</iframe>
```

Replace `YOUR_VIDSRC_EMBED_URL` with the embed URL appropriate for your application.
